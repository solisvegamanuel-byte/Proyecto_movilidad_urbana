# Análisis de Movilidad Urbana y Productividad Económica

Este proyecto analiza la relación entre la movilidad urbana (niveles de congestión, tiempos de viaje y retrasos) y la productividad económica (PIB per cápita y desempleo) en las principales ciudades del mundo. 

El objetivo es proporcionar un reporte fundamentado para orientar las decisiones de inversión en infraestructura de transporte, priorizando aquellas ciudades donde la mejora en la movilidad pueda impulsar el desarrollo económico y el bienestar social.

---

## 📊 Fuentes de Datos

El análisis integra dos fuentes de datos reales correspondientes al año 2024:
* **Movilidad urbana:** *TomTom Traffic Index* (indicadores de tráfico y tiempos de desplazamiento).
* **Economía urbana:** *OECD Cities* (PIB per cápita, desempleo y población).

---

## 💡 Preguntas de Negocio

El proyecto busca responder a las siguientes interrogantes clave:
1. **¿Qué ciudades presentan alta congestión y baja productividad económica?** (Zonas prioritarias de intervención).
2. **¿Cuáles muestran los mejores indicadores combinados?** (Movilidad eficiente y economía fuerte).
3. **¿Qué variables muestran mayor correlación con el desarrollo urbano?**

---

## 🎯 Objetivos del Análisis

Al completar este proyecto se ejecutaron los siguientes procesos:
* **Integración de datos:** Creación de un dataset único y consolidado a partir de fuentes heterogéneas.
* **Limpieza y estandarización:** Validación de tipos de datos, tratamiento de valores nulos e imputación según el contexto.
* **Filtrado temporal:** Enfoque del análisis exclusivamente en el periodo 2024.
* **Construcción de métricas:** Cálculo de indicadores agregados a nivel ciudad-año.
* **Análisis exploratorio (EDA):** Generación de visualizaciones para identificar patrones, distribuciones y correlaciones.
* **Documentación:** Registro estructurado del proceso en Jupyter Notebook y exportación del conjunto de datos final limpio.
