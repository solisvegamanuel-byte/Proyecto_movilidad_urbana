# Proyecto_movilidad_urbana
Proyecto de movilidad urbana (TripleTen)
En este proyecto de movilidad urbana mi objetivo como analista de datos fue buscar una posible relación con la productividad económica con la movilidad urbana de las principales ciudades de Latinoamérica, todo editando una copia del dataframe original mediante scripts de python en Jupyter Notebook.
